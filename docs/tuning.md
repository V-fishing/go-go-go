# 调优与排错

## 1. 算力 VISITS 取舍

| `--visits` | 单手耗时（RTX3050 热身后） | 棋力 | 适用 |
|---|---|---|---|
| 500–2000 | <1s | 弱/娱乐 | 快速连打、试跑 |
| 3000–8000 | ~1–2.7s | 强 | 默认/正式 |
| 8000+ | >2.7s | 更强但慢 | 挂机、追求质量 |

- 默认 `VISITS=8000`（`katago_play.py:775`），`--visits` 覆盖。
- 对方长考期用 `PRE_VISITS=350`（`:750`）预热续算，命中缓存即零延迟。
- 算力不足表现：漏算打吃/劫、应对慢被超时；调高即可。

## 2. 回合锁窗（TURN_LOCK）

- 对方落子确认后锁 `15s`（`TURN_LOCK_SECS=15.0`，`katago_play.py` 定义处），期间屏蔽重复落子确认、防重复点击；锁窗时长覆盖落子动画稳定期（实测 <8s，15s 充裕）。
- 回合推进**只由真实落子变化 + 弹窗应答驱动**，金框仅用于开局锚定与每轮视觉日志，**中途不再用金框翻回合**（旧版「等待期视觉校正翻回合」逻辑已删除，避免开局/横幅滞后造成的误翻）。
- 如仍偶发「对方落子后我方重复点同一点」：调大 `TURN_LOCK_SECS` 覆盖更长动画/网络滞后。

## 3. 识别失败排查清单

| 现象 | 根因 | 处理 |
|---|---|---|
| `未找到腾讯围棋窗口` | 客户端未开/未在对局页 | 打开腾讯围棋并进入对局，重跑（最长等 30s） |
| 全盘读不出棋盘 | 网格定位失败 | 重标定 `grid_calib.json`；检查 `_grid_cache` 是否被异常窗口污染 |
| 执色判反 | `avatar_calib.json` 过期/窗口缩放 | 重跑 `avatar_calib.py` |
| 落子点偏移 | 分辨率变/`grid_calib` 错位 | 重标定棋盘；校正 `MODE_GRID_OFFSET`（`board_reader.py:44`） |
| 一直误判对方行棋（我不落子） | `GOLD_ROI` 错位或阈值不对 | 见 [screenshots-calibration.md §5](screenshots-calibration.md) 重标定 |
| 误判我方行棋（乱点） | 金框横幅滞后 + 锁窗被绕过 | 检查 `TURN_LOCK`、`_vis_flipped` 逻辑；确认未误改 `GOLD_THR` |
| 续战不点 | 结算页按钮文字不匹配 `REMATCH_KEYS` | 检查 OCR 是否输出「重新匹配/续战」；放宽关键词 |
| OCR 无输出 | 系统缺 OCR 语言包 | 安装「Windows 显示语言」离线包（OCR 用用户语言引擎） |
| 落子后读半截盘面 | 提子动画中读盘 | 已内置「等动画稳定后重读」（`:1950`），若仍抖，调大稳定等待 |
| 劫争连点报错 | 未识别劫点 | 确认 `br.detect_ko` 生效（`:1678`），劫点加入 `banned` |

## 4. 已知问题与规避

1. **悬停预览方块**：空盘时我方光标压格显示实心方块会被读成唯一子 → 已用 `strip_hover_square()`（`katago_play.py:346`）归零；若仍误判，确保光标不在唯一空格上启动。
2. **悔棋/闪烁**：读盘出现 0 新增子当作闪烁忽略（`:1496`）；若对方悔棋导致盘面减少，主循环不会主动回退，需人工重锚定。
3. **分先换色**：自动续战到新局时由角标核查执色（`:1740`），`color_observer_loop` 仅观察不改判定；若分先换色判错，新局会全程执色反 → 遇此暂停并手动确认。
4. **窗口重建**：对局重开时渲染窗口句柄可能变化，`post_click` 自动重找一次（`winclick.py:185`–`:203`）；极端情况（多实例）可能点错，确保只开一个腾讯围棋。
5. **多显示器/缩放**：坐标基于窗口 `GetWindowRect` 与 `DPI`；若系统缩放非 100%，截图与点击坐标可能错位 → 建议运行环境设为 100% 缩放并固定窗口尺寸，标定后勿改。

## 5. 日志与可观测性

- 主程序 stdout 经 `_Tee` 镜像到 `katago_ui.log`（`main():1077`），UI 日志区同步显示。
- 关键日志标记：`[锚定]`、`[视觉行棋]`、`[锁帧]`、`[角标并行]`、`[重新匹配]`、`[按钮映射]`、`[popup]`。
- 实时棋盘镜像：`katago_ui.py` 的 `poll_board` 调 `br.read_current`（UI 侧），可与腾讯围棋画面逐格核对。

## 6. 不要做的

- 不要恢复已删除的判据（绿框 obox / 徽章 geo / 子数奇偶算术 / 自学习 `_VIS_REF`）：它们已被证明区分度低、易误翻，金框唯一判据是当前稳定方案。
- 不要依赖「横幅 OCR 即时翻转回合」：`ocr_turn` 仅作参考，金框才是真值。
